# s21_decimal — Библиотека для работы с типом Decimal

Учебный проект School 21: реализация библиотеки для работы с 96-битным
типом Decimal (аналог System.Decimal из C#) на языке C.

## Структура типа

```c
typedef struct {
    unsigned int bits[4];
} s21_decimal;
```

- `bits[0]`, `bits[1]`, `bits[2]` — 96-битная мантисса (целое число)
- `bits[3]` — знак (бит 31) и масштаб/scale (биты 16–23), определяющий
  положение десятичной точки (степень 10, на которую делится мантисса)

---

## ✅ Реализованные функции

### Знак и масштаб

| Функция | Описание |
|---|---|
| `s21_set_sign(s21_decimal *d, int sign)` | Устанавливает знак числа: 0 — положительное, 1 — отрицательное |
| `s21_get_sign(s21_decimal d)` | Возвращает знак числа (0 или 1) |
| `set_scale(s21_decimal *d, int scale)` | Устанавливает масштаб (0–28), не затрагивая знак |
| `get_scale(s21_decimal d)` | Возвращает текущий масштаб |

**Сложность:** знак и масштаб хранятся в одном и том же 32-битном слове
(`bits[3]`), поэтому важно менять их через битовые маски (`&`, `|`, `~`),
а не через прямое присваивание — иначе можно случайно затереть соседние
данные.

### Битовые операции

| Функция | Описание |
|---|---|
| `set_bit(s21_decimal *d, int bit, unsigned int value)` | Устанавливает конкретный бит (0–127) в 0 или 1 |
| `get_bit_value(s21_decimal d, int bit)` | Считывает значение конкретного бита |
| `get_bit_position(int index)` | Вспомогательная: переводит номер бита (0–127) в пару (индекс массива, локальная позиция) |

**Сложность:** мантисса растянута на 3 отдельных `int`, поэтому перед
установкой бита нужно сначала вычислить, в каком именно `int` он
находится (`index = bit / 32`) и на какой позиции внутри него
(`localPosition = bit % 32`).

### Операции над мантиссой (внутренние помощники)

| Функция | Описание |
|---|---|
| `multiply(s21_decimal *d, unsigned int m)` | Умножает 96-битную мантиссу на число, возвращает 1 при переполнении |
| `divide(s21_decimal *d, unsigned int div)` | Делит 96-битную мантиссу на число |
| `equalize_scales(s21_decimal *d1, s21_decimal *d2)` | Приводит два числа к одинаковому масштабу для сравнения |
| `is_less_mentissa(s21_decimal d1, s21_decimal d2)` | Сравнивает только мантиссы (без учёта знака) |

**Сложность:** так как мантисса — это 96 бит, а обычный `int`/`long long`
не может её вместить, умножение и деление реализованы вручную:
через перенос (carry) между `bits[0] → bits[1] → bits[2]` при умножении
и через остаток (remainder), идущий в обратную сторону — при делении.
Использовать здесь `long long` для промежуточных вычислений обязательно,
иначе будет переполнение на middle-шаге.

### Сравнения

| Функция | Описание |
|---|---|
| `s21_is_equal` | Равенство (учитывает разный scale и ±0) |
| `s21_is_not_equal` | Неравенство |
| `s21_is_less` | Меньше |
| `s21_is_less_or_equal` | Меньше или равно |
| `s21_is_greater` | Больше |
| `s21_is_greater_or_equal` | Больше или равно |

**Сложность:** числа с разным `scale` могут представлять одно и то же
значение (`3.14` при scale=2 и `3.140` при scale=3), поэтому перед
сравнением мантиссы приводятся к одинаковому масштабу через
`equalize_scales`. Также отдельно обрабатывается случай `+0 == -0`.

### Конвертация

| Функция | Описание |
|---|---|
| `s21_from_int_to_decimal` | int → decimal. Корректно обрабатывает `INT_MIN` |
| `s21_from_decimal_to_int` | decimal → int. Отбрасывает дробную часть, проверяет переполнение |
| `s21_from_float_to_decimal` | ⚠️ **не завершена** (см. ниже) |
| `s21_from_decimal_to_float` | ⚠️ **не реализована** |

### Прочее

| Функция | Описание |
|---|---|
| `s21_negate(s21_decimal v, s21_decimal *result)` | Меняет знак числа на противоположный |

## ⚠️ Не реализовано / требует доработки

- **`s21_from_float_to_decimal`** — сейчас функция считывает scale из
  строки, но не заполняет мантиссу (`insert_mantissa`/аналог не вызван),
  поэтому число всегда получается равным 0. Также не обрабатываются
  `inf`, `nan` и переполнение диапазона.
- **`s21_from_decimal_to_float`** — не реализована.
- **`s21_truncate`, `s21_floor`, `s21_round`** — не реализованы. Должны
  использовать `divide` в цикле по 10 для избавления от дробной части.
- **Арифметика: `s21_add`, `s21_sub`, `s21_mul`, `s21_div`** — не
  реализованы. Это самая сложная часть проекта: `s21_mul` потребует
  промежуточного 192-битного числа (мантисса × мантисса может не
  влезать в 96 бит), а `s21_div` — деление в столбик бит за битом.
- **Makefile** — есть базовые цели, но нужно проверить актуальность
  списка `.c`-файлов при добавлении арифметики.
- **Тесты** — покрыты: биты, знак, масштаб, `multiply`, `negate`,
  сравнения, `from_int_to_decimal`. Не покрыты: конвертация float,
  truncate/floor/round, арифметика (их ещё нет).

---

## Известные проблемные места в текущем коде

1. В `s21_converters.c` функция `s21_from_decimal_to_int` использует
   `divide`, но не проверяет код ошибки, который она возвращает
   (если `divide` вернёт 1, это будет проигнорировано).
2. В `s21_from_float_to_decimal` мантисса никогда не заполняется —
   нужно добавить вызов функции вставки цифр из строки в 96 бит
   (по аналогии с тем, как строится число из строки цифра за цифрой:
   `multiply(dst, 10)` + прибавление цифры на каждой итерации).
3. `double_to_string` содержит опечатку в формате: `"%.15gf"` — лишняя
   `f` в конце формата `%g` не нужна и может привести к мусору в конце
   строки.
